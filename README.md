# Aula de Portugol Studio

Este repositório contém exercícios e projetos básicos desenvolvidos na aula de **Portugol Studio**, com foco em **lógica de programação**.

**Local de ensino:** Escola/Curso [Nome da Escola]  
**Data:** 04/03/2026

## Conteúdo

1. **Variáveis e tipos de dados**
   - Inteiro, Real, Caractere, Lógico
2. **Entrada e saída**
   - `leia()` e `escreva()`/`escreval()`
3. **Condicionais**
   - `se`, `senao`
4. **Laços de repetição**
   - `enquanto`, `para`
5. **Exercícios resolvidos**
   - Soma de números
   - Verificação de par ou ímpar
   - Média de notas de alunos

## Objetivo
Praticar **lógica de programação** e entender a estrutura de algoritmos antes de migrar para linguagens como C, Java ou Python.
